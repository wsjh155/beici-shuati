# 背词刷题 · 微信小程序

一个专注「背单词 + 刷题」的微信小程序：内置中考 / 高考 / 四级 / 六级 / 考研 / 雅思六个等级的官方词库，结合艾宾浩斯遗忘曲线安排复习，并支持题库练习、错题回顾、学习记录批量管理。

## 功能

- **六大等级词库**：完整词库 / 高频词库，订阅后自动加入总计划
- **总计划池**：把想学的单词、题目加入总计划，按每日配额推进
- **背词计划 / 刷题计划分开**：每日新词、复习量、每日刷题量独立设置
- **乱序 / 顺序可选**：背单词与刷题各自有全局顺序；**计划页还能逐个词库、逐个题库单独设顺序**（点名字即按该顺序开始），学习/刷题页顶部也能一键切换并即时重排剩余卡片
- **学习记录**：查看学过的单词与做过的题，支持全选 / 批量删除（删除即重学）
- **错题回顾 / 学习统计**
- **刷题选科目**：刷题页可勾选要练的科目（题库），今日刷题只从所选科目出题；内置化学考研三门 + 数学 / 英语语法 / 政治 + 考研 / 六级 / 雅思 / 四级核心词汇，共 6700+ 题
- **题库仅自己可见**：私有题库与题目都按 `owner_id = auth.uid()` 做行级安全（RLS），他人无法读取
- **预设题库（公开）**：英语类 5 个题库共 3382 题作为公开预设，所有人都能在订阅中心选择性订阅
- **上传自己的题库 / 词库**：仓库保留完整实现（`pages/upload` + `shared_libraries` / `shared_library_items`），但**提审版默认关闭公开发布入口**，原因见下方合规清单；开启前必须先接入微信官方内容安全接口
- **订阅与管理分离**：「预设题库 · 订阅」只负责订阅（官方预设题库 / 官方词库 / 精选共享内容）；「题库 / 词库总览」只负责管理自己的内容，可单独练习或取消订阅（级联清理题目、计划与作答记录）
- **数据云同步**：换设备不丢失
- **先体验后登录**：未登录即可浏览首页、功能介绍、官方预设题库/词库，并可直接**试学单词卡片、试练刷题判分**；登录只由用户主动点击触发，且任何登录环节都有「暂不登录」可取消选项

## 技术栈

- 微信小程序原生（WXML / WXSS / JavaScript）
- WorkBuddy 云服务 / PostgreSQL（含 RLS 行级安全）
- `utils/store.js` 作为统一数据访问层，页面不直接拼查询

## 本地运行

1. 用「微信开发者工具」导入本目录
2. 在 `project.config.json` 填入你自己的小程序 appId
3. 云服务配置见 `utils/cloud.js`（endpoint / publishableKey / OAuth clientId），需自行准备后端
4. 编译预览

## 登录合规说明（微信审核）

按《小程序帐号登录功能规范》整改，适用于「服务范围开放」的小程序：

1. 打开小程序**不跳转登录页、不弹强制登录窗**；首页先展示功能介绍、快捷入口与今日计划，用户可先了解/体验功能。
2. 游客态可浏览首页、四个 tab 页、官方预设题库/词库与精选共享内容，还能点「开始学习 / 开始刷题」**完整体验卡片背词与答题判分**（试学/试练读公开示例内容，不写入任何个人数据）。
3. 登录入口均由**用户主动点击**触发：游客提示条、「我的」页「点击登录」、试学/试练页的「登录保存进度」。
4. 登录以底部弹层呈现，提供醒目的「**暂不登录**」按钮，点遮罩也可关闭；取消后仍可继续浏览，不影响任何非账号功能。
5. 订阅、导入、保存计划、创建题库等需要账号的操作，只打开上述可取消弹层进行引导，不强制跳转、不阻断浏览。
6. 登录方式为微信一键登录（`wx.login` + 服务端换取会话），**无账号密码**，不获取昵称 / 头像 / 手机号；提审时建议附功能截图或录屏协助审核。

## 提审合规清单（v1.5.0）

| 风险点 | 处理 |
|---|---|
| 先体验后登录 | 游客可浏览 + 试学 / 试练，登录弹层随时可取消 |
| 用户协议 / 隐私政策 | `pages/agreement`，登录弹层、「我的」页、关于页均可进入；含账号注销与数据删除方式 |
| 账号注销 / 数据删除 | 「我的 → 删除我的数据」二次确认后按依赖顺序清理私有表、共享内容与举报记录，再退出登录 |
| UGC 公开发布 | `utils/config.js` 的 `ENABLE_UGC = false`；`pages/upload` 未注册到 `app.json` 且加入打包忽略；共享库仅官方整理内容 |
| 内容安全 | `utils/content-security.js` 做提交前本地初筛，已接入导入页与上传页；**开放 UGC 前仍须接入 `msgSecCheck` / `imgSecCheck` 并完成类目报备** |
| 举报机制 | 订阅中心每张共享卡片可举报（游客也可用），`library_reports` 累计 3 次自动下架（同一账号去重） |
| 生成式 AI | `ENABLE_AI = false`；拍照页改为手动录入，`utils/ai.js` 不打包，发布包内无任何大模型调用 |
| 外部域名 / 功能可用性 | `ENABLE_PRONUNCIATION = false` 时隐藏发音入口，避免未配置 downloadFile 合法域名导致审核员看到「发音加载失败」 |
| 付费 / 广告 / 外链跳转 | 无支付、无广告、无内购、无第三方统计 SDK；开源地址仅可复制，不做页面跳转 |

提审前还需在**小程序后台**完成（代码仓库无法代办）：

- 小程序备案、选择合适服务类目（建议「工具 / 效率」或「教育 / 学习工具」）
- 配置「用户隐私保护指引」，与本仓库隐私政策所列信息一致（匿名账号标识、学习内容）
- 配置服务器域名：云服务 `https://mp-api.app.workbuddy.host`（request 合法域名）
- 若要恢复单词发音，把 `https://dict.youdao.com` 加入 **downloadFile 合法域名**，再把 `utils/config.js` 的 `ENABLE_PRONUNCIATION` 改为 `true`
- 在 `project.config.json` 填入自己的 appId（当前为 `touristappid`）
